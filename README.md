# Gastro Books

**Gastronomy payroll, bookkeeping, and backoffice services.**

This is the source for the marketing landing page at [mygastrobooks.de](https://mygastrobooks.de).

## Stack

- [Vite](https://vitejs.dev) 6
- [React](https://react.dev) 19
- [TypeScript](https://www.typscriptlang.org) 5.8
- [Tailwind CSS](https://tailwindcss.com) 4
- [Lucide icons](https://lucide.dev)

## Run locally

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Build

```bash
npm run build     # outputs to dist/
npm run preview   # serve the production build locally
npm run lint      # TypeCheck
```

## Deploy

The `dist/` folder can be deployed to any static hosting (Vercel, Netlify, Cloudflare Pages, etc.). No server-side keys or environment variables needed.
